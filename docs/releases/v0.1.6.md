# duobrain v0.1.6

The first duobrain release published on npm. In the product repository, run:

```sh
npx duobrain@0.1.6 install
```

## Fixed

- **Updates from an npm install.** npm publishes `repository.url` as `git+https://…`. `install` copied it
  into `VENDOR.json` as the update source, and Git cannot fetch a `git+https` URL, so `update` from an
  npm-installed copy would have failed. `install` now records the plain Git URL, and `update` also
  accepts a source that still carries the prefix. v0.1.5 was found to have this problem before it was
  published to npm, so it is available from Git only.

## Upgrading

Nothing changes for copies installed from Git: `node .duobrain/bin/duobrain.js update` moves to v0.1.6.

## Verification

A new test installs from an npm-style copy (no `.git`, `git+` repository URL) and checks that
`VENDOR.json` records the plain source and that `update --check` reaches the release tags.
