# duobrain v0.1.3

The dashboard becomes a two-person board you can keep open: who is on what, whose turn each request is,
and how the work flowed — plus updating duobrain without leaving it.

## Changed

- **New layout.** A charcoal-and-lime sidebar holds `Now`, `Requests`, `Flow` and `Wiki`, shows both
  people's current state on every tab, and collapses to icons. Narrow windows switch to icons on their own.
- **Now** leads with the shared goal and plan state, then a card per person (working on, up next, stuck on)
  and open requests written as sentences with whose turn it is.
- **Requests** pairs request cards with a detail pane (turn, progress, timeline, evidence). `J` / `K` move
  between requests.
- **Flow** places sessions, request events and wiki notes in two lanes, one per person, in recorded order,
  next to recorded-time totals, blockers and per-area time.
- **The dashboard knows who you are.** With `--repository`, the checkout's local identity
  (`duobrain init --participant`) marks your requests as `Your turn`, and the sidebar shows your profile
  nickname and GitHub login. Without an identity you pick yourself once in that browser.
- **Sharing status comes first.** A card under the logo says whether your records reached your partner
  (`Shared with partner · 5m ago`, `Not shared yet`, `Sharing failed`) and when the page last re-read them.
- **English by default.** The dashboard uses Korean only when the browser's first language is Korean; the
  sample data follows the same language.

## Added

- **Update from the dashboard.** `Check for updates` at the bottom of the sidebar compares versions, lists
  the new commits and asks before doing anything. It runs this copy's own `duobrain update`, so the same
  safety checks apply. Restart the dashboard afterwards; a vendored copy also reminds you to commit
  `.duobrain/` and `AGENTS.md`.
- **Daily update check.** Once a day the dashboard quietly checks for a new release and turns the sidebar
  button into a lime `Update to vX.Y.Z`. It never installs on its own and can be turned off.
- **Settings tab** for language (Automatic, English, 한국어), auto-refresh interval, sidebar labels and the
  running version.

## Notes

- The dashboard stays read-only for project records. The one exception is updating duobrain itself after
  you confirm, and that request is accepted only from the dashboard page (custom header plus matching
  `Host` and `Origin`), so other sites cannot trigger it.
- New endpoints: `GET /api/meta` (running version) and `GET`/`POST /api/update`. Repository snapshots now
  include `viewer`, the local participant ID; no other local state is exposed.
- The dashboard is local to this computer (`127.0.0.1`) and is designed for desktop windows.

## Verification

The suite contains 112 tests, including update-request protection, error-code-only failure reports, the
local identity reaching the dashboard from a real engine store, and a guard against hard-coded Korean
outside the Korean dictionary.
