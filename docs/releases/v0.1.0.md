# duobrain v0.1.0

duobrain gives exactly two people and their existing AI tools a shared project memory backed by Git.
This first release includes a local engine, read-only dashboard, and AI collaboration guides under the MIT license.

## Included

- Shared plans, roles, scoped sessions, overlap checks, and handoffs on an isolated `duobrain/state` branch.
- Information requests with source evidence and human feedback requests with attributable responses.
- Source-preserving wiki records, search, captured-method comparison, and optional daily refinement.
- Resumable AI-led onboarding, participant nicknames, and local dashboard locale preferences.

## Run

Requires Node.js 22+ and Git; no `npm install` is needed.

```sh
git clone --branch v0.1.0 https://github.com/slowspurt/duobrain.git
cd duobrain
node bin/duobrain.js --version
node src/dashboard/run.js
```

Open `http://127.0.0.1:4173` for sample records. To connect a real two-person project, follow
[Getting started](https://github.com/slowspurt/duobrain/blob/v0.1.0/GETTING_STARTED.md).
Keep the tool checkout separate from the product repository and pass its path with `--repository`.

## Verification and limits

The local engine, wiki, and dashboard suite contains 87 tests. Release preparation also runs
the concurrent-work, plan-refinement, and scheduled method-refinement scenarios against temporary Git repositories.
CI is configured for Node.js 22 and 24 on Linux and macOS; configuration alone is not a passing CI run.

Actual acceptance with two people on separate machines and their existing AI tools remains pending.
There is no background AI service, automatic partner wake-up, real-time lock, or bundled scheduler.
The dashboard reads locally synchronized records; pending delivery requires `sync` retries.
Locale preferences are stored, while translated dashboard controls remain follow-up work.


Distribution is through GitHub source archives and Git checkout. No npm package is published.
