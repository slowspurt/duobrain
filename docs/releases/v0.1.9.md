# duobrain v0.1.9

Chart tokens for the pages you build next to duobrain — a manual for a specific task, a data-analysis or
data-tracking dashboard — so your charts use duobrain's colors instead of a palette of their own. In the
product repository, run:

```sh
npx duobrain@0.1.9 install
```

Design tokens: added --duo-chart-series-1–5, --duo-chart-other, --duo-chart-single, --duo-chart-highlight, --duo-chart-highlight-line, --duo-chart-sequential-1–5, --duo-chart-diverging-negative, --duo-chart-diverging-neutral, --duo-chart-diverging-positive, --duo-chart-grid, --duo-chart-axis, --duo-chart-label, --duo-chart-empty, --duo-chart-line-width, --duo-chart-line-width-detail, --duo-chart-marker-size, --duo-chart-bar-radius, --duo-chart-gap

## Added

- **Chart colors from duobrain's palette.** Series 1 and 2 are the two people's colors, so a two-person
  chart needs nothing else; series 3–5 are terracotta, steel blue and olive, and anything further folds
  into a gray `--duo-chart-other`. All five clear 3:1 on white and stay apart for color-blind readers;
  charts where any two colors can touch, such as scatter plots, read well up to three series.
- **One series, one highlight.** `--duo-chart-single` draws a series in charcoal and
  `--duo-chart-highlight` lights the mark that matters — this week, or you — in lime.
- **Scales.** A lime-to-forest sequential scale for how much (start at step 2 for ordered steps such as
  stages) and a terracotta / steel-blue diverging pair around a neutral midpoint.
- **Chart chrome and marks.** Gridlines, axis and label colors that reuse the dashboard's line and text
  tokens; 2px lines, 1px detail lines, 8px points, 4px rounded bar ends and a 2px gap between fills;
  `--duo-chart-empty` for heatmap cells with nothing recorded.
- **Samples on the tokens page** (`/tokens`): a short line chart with labels at the line ends, bars with a
  lime highlight, a 90-day chart with raw values in thin gray and each person's 7-day average, and a
  year heatmap with one cell per day.

## Changed

- Between releases, `npm run release:check` only requires the `Design tokens:` line, so CI stays green
  while tokens change; the comparison with the previous release tag still runs when a release is cut.
- The npm publish workflow fetches tags, which that comparison needs.

No existing token changed, so pages built on 0.1.8 keep their look. Nothing in the work record changed,
so a partner on 0.1.8 keeps working. See
[docs/design-tokens.md](https://github.com/slowspurt/duobrain/blob/v0.1.9/docs/design-tokens.md#charts)
for how to use the chart tokens.

## Verification

The suite contains 135 tests. The chart colors were checked with a color-blind simulation (worst adjacent
separation 9.6, target 8) and for 3:1 contrast on white; the sequential scale reads one hue, light to
dark, with its ordered steps clearing 2:1.
