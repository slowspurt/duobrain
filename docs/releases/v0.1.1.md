# duobrain v0.1.1

One person adds duobrain to the project, and the other only pulls and joins.

## Changed

- **Vendored install.** `install` copies duobrain's runtime files (about 400KB, no dependencies) into
  `.duobrain/` in the product repository and pins the release in `.duobrain/VENDOR.json`. It also writes
  the `AGENTS.md` block, the `CLAUDE.md` import and a `.gitattributes` line that marks the folder as
  vendored. Commit them once; the second person gets duobrain by pulling.
- **Joining.** `init --participant <id>` reads the participant pair from the shared record, so the second
  person no longer repeats both IDs. Without shared state it fails before creating anything locally.
- **Updating.** In a vendored project, `update` installs the newest `vX.Y.Z` release, or `--ref vX.Y.Z`,
  and refreshes `AGENTS.md` with the new code. One person updates and commits; the other pulls. It only
  moves to a newer version without `--ref`, and refuses to overwrite local edits in `.duobrain/`.

[Why duobrain is vendored](https://github.com/slowspurt/duobrain/blob/v0.1.1/docs/vendoring.md) explains
the approach and its trade-offs. The global install from v0.1.0 (`npm link`, `duobrain guide`) still works.

## Run

```sh
git clone --depth 1 --branch v0.1.1 https://github.com/slowspurt/duobrain.git /tmp/duobrain
cd /path/to/product
node /tmp/duobrain/bin/duobrain.js install
node .duobrain/bin/duobrain.js init --participants member-a,member-b --participant member-a
```

The other person, after pulling: `node .duobrain/bin/duobrain.js init --participant member-b`.
See [Getting started](https://github.com/slowspurt/duobrain/blob/v0.1.1/README.md#get-started).

## Verification and limits

The suite contains 107 tests, including an end-to-end vendoring test: one clone installs and connects,
a second clone joins with only `init --participant`, and `update` installs a newer local release.
Release preparation also runs the three scenario checks against temporary Git repositories.

Actual acceptance with two people on separate machines and their existing AI tools remains pending.
Vendoring adds duobrain's files to the product repository; see the trade-offs in the vendoring guide.
